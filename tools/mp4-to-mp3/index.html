How It Works

When you select a video, this tool decodes its audio track right inside your browser using the Web Audio API, then hands the raw audio off to a background Web Worker that encodes it into MP3 — so the page never freezes, even on large batches. Several files are encoded in parallel across multiple workers at once. The entire process happens on your own device: the file is never sent over the internet, which keeps things fast and keeps your files private. To convert several videos at once, just select all of them, click "Convert All," and (if Auto ZIP is checked) a single ZIP with every MP3 downloads automatically when everything finishes.

Frequently Asked Questions

Does my video get uploaded to a server?

No. This tool runs entirely inside your browser, using a background Web Worker for encoding. Your video file is never uploaded to the internet.

Can I convert multiple videos at once?

Yes — select or drag-and-drop several videos, they convert in parallel across background workers, and you can download everything as one ZIP file.

Does this work offline?

Install MP4 to MP3 Converter as an app (or visit once over HTTPS) and this page keeps working without an internet connection.

Which formats are supported?

MP4, MOV, WEBM, and any other format your browser is able to decode.
