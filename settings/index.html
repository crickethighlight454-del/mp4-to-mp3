Your browser doesn't support setting a custom save folder (this needs Chrome or Edge, on desktop or Android). Files will download to your browser's usual Downloads location — most browsers let you turn on "Ask where to save each file" in their own settings if you'd like to choose per download instead.

How this works

ToolBox uses your browser's File System Access API to remember a folder you've approved — the same permission model used by desktop apps, just scoped to one folder. Nothing about your files or your folder is ever sent anywhere; the handle is stored only on this device, in this browser. If you ever revoke folder access from your browser's site settings, ToolBox simply falls back to a normal download and you can pick a folder again here.
