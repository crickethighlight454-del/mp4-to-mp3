Yeh Kaise Kaam Karta Hai

Jab aap koi video select karte hain, yeh tool aapke browser ke andar hi (Web Audio API ke zariye) us video ki audio track ko decode karta hai, phir usay MP3 format mein encode kar deta hai. Yeh poora process aapki apni device par hota hai — file kabhi internet par nahi jaati, is liye aapki privacy aur bandwidth dono bachte hain. Ek saath kai videos convert karne ke liye bas sab files select karein aur "Sab Convert Karein" par click karein.

Aksar Poochhay Jane Wale Sawalat

Kya meri video kisi server par upload hoti hai?

Nahi. Yeh tool poora aapke browser ke andar chalta hai. Video file kabhi bhi internet par upload nahi hoti.

Kya main ek saath multiple videos convert kar sakta hoon?

Ji haan — bohat sari videos select ya drag-drop karein, sab ek saath convert hongi, aur ek ZIP mein download bhi ho sakti hain.

Kya yeh offline bhi kaam karta hai?

Ek baar page load hone ke baad, yeh PWA hai — install kar ke bina internet ke bhi istemal kiya ja sakta hai.

Konsi formats support hoti hain?

MP4, MOV, WEBM aur wo tamam formats jo aapka browser decode kar sakta hai.
